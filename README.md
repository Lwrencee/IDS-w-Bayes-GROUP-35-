# AI-Based Network Intrusion Detection System (Group 35)

## Project Overview
This project implements a Hybrid Intrusion Detection System using Gaussian Naive Bayes. It is designed to analyze packets and detect network anomalies based on metadata.

## Features
- **Real-time Dashboard:** Built with Streamlit.
- **Forensic Analysis:** Logarithmic scatter plots for identifying outliers.
- **Visual Data Representation:** Represents results using a pie chart, and a table.
- **Hybrid Logic:** Combines probabilistic AI with context-aware rules.

## Installation & Run
1. Clone the repo:
   ```bash
   git clone [https://github.com/Lwrencee/IDS-w-Bayes-GROUP-35-.git](https://github.com/Lwrencee/IDS-w-Bayes-GROUP-35-.git)
2. Install dependencies:
   pip install -r requirements.txt
3. Run the app:
   streamlit run app.py
